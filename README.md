# Hackaton-Kodland

Eric: Calculadora de emissão de carbono com recomendações de como diminuí-las.

Uma calculadora que faz perguntas genéricas acerca do seu consumo e liberação de carbono na atmosfera. (Exemplo: quantos quilômetros você anda de carro por semana?)
Baseado em suas respostas, o programa poderá ver o que pode ser feito para diminuir essa liberação, assim ajudando no problema da mudança climática.
O projeto pode ser feito em Python e o uso de uma Inteligência Artificial pode ajudar para criar perguntas personalizadas e/ou criar recomendações personalizadas baseado nas suas respostas.

Opções de uso para a checklist
1 - A implementação proposta está funcionado?
2 - Todos os comandos executam sem erros e retornam a resposta correta?
3 - O codigo é facil de ler e é bem estruturado?
4 - O usuário consegue achar as funcionalidades com facilidade?
5 - O seu projeto ajuda o usuário de alguma maneira (não é perda de tempo)?
6 - O seu projeto é divertido (induz o usuário a usá-lo mais vezes)?
